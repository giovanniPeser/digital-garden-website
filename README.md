# Digital Garden Landing Page 🪴

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Version](https://img.shields.io/badge/version-1.3.0-green.svg)](https://github.com/pesericog6/sitoApp)
[![PWA](https://img.shields.io/badge/PWA-Ready-blue.svg)](https://pesericog6.github.io/sitoApp/)

The official landing page for **Digital Garden**, a smart botanical companion app for Android. This website is built with a focus on performance, accessibility, and professional web standards.

[**Live Demo**](https://pesericog6.github.io/sitoApp/)

## 🚀 Key Features

- **Full Localization**: Support for English, Italian, French, German, and Spanish with localized screenshots.
- **Progressive Web App (PWA)**: Fully installable on mobile devices with offline support via Service Workers.
- **SEO Optimized**: Implements JSON-LD structured data, Open Graph tags, and localized meta descriptions.
- **Modern UI**: Smooth reveal-on-scroll animations and interactive screenshot slider.
- **Security First**: Strict Content Security Policy (CSP) and no inline JavaScript.

## 🛠️ Technical Stack

- **HTML5**: Semantic structure for maximum accessibility (WCAG compliant).
- **CSS3**: Material Design-inspired styling with dark mode support and custom-themed components.
- **ES6+ JavaScript**: Clean, documented code following the Google JavaScript Style Guide.
- **Service Workers**: Advanced caching strategies for near-instant load times.
